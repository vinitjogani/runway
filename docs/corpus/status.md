# Corpus status

Runway is measured against a corpus of popular, permissively licensed,
open-source macOS apps written in Swift: Maccy, Rectangle, Stats, HiddenBar,
CodeEdit, NetNewsWire, LinearMouse, MonitorControl, Clipy, SwiftBar,
AeroSpace, Amethyst, Gifski, FSNotes, KeyboardCowboy and VirtualBuddy. The
list, with each app's licence and pinned commit, is in
[`Tools/corpus/apps.json`](../../Tools/corpus/apps.json). Apps were left out
after checking when their licence (GPL-3.0, Commons Clause) or language
(Objective-C) didn't fit.

The clones live outside the repository, in `RUNWAY_CORPUS_DIR` (default
`~/.cache/runway-corpus/apps`).

## Results

- [**Xcode project import**](import-results.md): how each app stages and
  builds with `runway stage` and `runway build`, with no configuration, and
  the first compile error it hits. In the latest run 13 of 16 apps stage;
  their first errors are API gaps in Runway's frameworks or Mac-only code in
  dependencies (CoreAudio, Objective-C packages, IOKit and private headers).
  Two apps hit staging bugs (marked **tool**) and the Tuist-only app isn't
  read.
- [**Interface Builder documents**](../../Tools/corpus/ib-results.md): every
  `.xib` and `.storyboard` in the corpus (57 documents, all loaded) read by
  Runway's AppKit without the apps' code, with what isn't read yet.
  Generated by `swift run RunwayIBCheck <corpus> --markdown
  Tools/corpus/ib-results.md`.

## Running the corpus tools

All scripts are in [`Tools/corpus`](../../Tools/corpus) and only need
Python 3.

```sh
python3 -I Tools/corpus/analyze.py fetch    # clone missing apps (shallow)
python3 -I Tools/corpus/analyze.py          # static gap report: report.md / report.json
python3 -I Tools/corpus/analyze.py query type NSStatusItem
python3 -I Tools/corpus/scoreboard.py       # real `runway build` of each app: scoreboard.md
```

`analyze.py` is static text analysis: it never builds or runs what it reads.
`scoreboard.py` builds each app, its local packages and its Apple-framework
dependencies, records how far each gets, and launches apps that build under
Xvfb. Their reports can include local build paths, so they are ignored by
git.
