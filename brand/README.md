# Runway brand

- `logo.svg`: the app mark (a runway running to the horizon on a night-to-blue tile). `logo-512.png` is the same at 512 px.
- Accent: `#1d64d8` on light, `#5a9cff` on dark (text: `#1652b8` / `#86b6ff`); tile gradient `#0b1f4d` → `#1d64d8`.
- Type: Geist and Geist Mono.
- In running text the name is always "Runway".
