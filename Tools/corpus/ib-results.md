# Interface Builder documents in the corpus

Generated by `swift run RunwayIBCheck <corpus> --markdown Tools/corpus/ib-results.md` (Tools/ib-check): every macOS `.xib` and `.storyboard` loaded headlessly by Runway's AppKit **without the apps' code** — each xib with a stand-in File's Owner, each storyboard's Application scene plus every controller scene, with views and windows loaded. App classes (`customClass`) can't be found without the app (Runway uses the AppKit base class instead, as Cocoa would fail to), so outlets to them aren't set here; in a staged app the generated class table supplies them.

What "not read" means: the loader marks every attribute and child element it reads; anything left is listed at the end. Known gaps behind the remaining entries: attributed-string runs (`<attributedString>` fragments' fonts and colours: the text is used, its styling isn't — most of the `font.*`/`color.*` attributes), cell-based table data cells (`dataCell` where a column has no view prototype), `NSPathControl`, `WKWebView` (a plain view stands in: WebKit sits above AppKit), view shadows, input source locales of secure fields, and custom `NSCell` subclasses. Window positioning masks, popup button `behavior` and other Xcode bookkeeping are read and deliberately ignored.
